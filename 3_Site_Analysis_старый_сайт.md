### Блок 1. Технический аудит

#### 1.1. Индексация

**Вывод:** индексация в Google крайне низкая, вероятно из-за отсутствия robots.txt и sitemap.xml. Гипотеза по Яндексу требует ручной проверки.

#### 1.2. Редиректы и дубликаты — КРИТИЧНО

Обнаружен **каскад проблем с дублированием контента**, каждая из которых множит количество дублей:

| Проблема | Статус | Влияние |
|---|---|---|
| http:// → https:// | **Нет редиректа** — http отдаёт 200 OK | ×2 дубль каждой страницы |
| www → без www | **Нет редиректа** — www отдаёт 200 OK | ×2 дубль каждой страницы |
| gubernskayahotel.ru (без дефиса) | **Нет редиректа** — отдаёт 200 OK, тот же контент | ×2 дубль всего сайта |
| /index.php | **Нет редиректа** — отдаёт 200 OK (главная страница) | Дубль главной |
| Trailing slash | URL без `/` в конце отдаёт другую страницу с кодом 200 | Непредсказуемое поведение |

**Совокупный эффект:** каждая страница сайта существует минимум в **6 версиях** (http/https × www/non-www × gubernskaya-hotel.ru/gubernskayahotel.ru). Для ~50 страниц это ~300 дублей. Без canonical и без robots.txt поисковики должны самостоятельно определять каноническую версию, что приводит к «размазыванию» веса.

**Подтверждение trailing slash:** URL `/gubernskaya/rooms/202` (без слэша) возвращает 200 OK с title «Цены на номера в гостинце Губернской ✔ Стоимость проживания в Шерегеше 2020–2021» и H1 «Выбор номера» — это страница листинга номеров, а не конкретный номер 202. При этом `/gubernskaya/rooms/202/` (со слэшем) отдаёт правильную страницу номера. Дополнительно: в title листинга обнаружены **опечатка** («гостинце» вместо «гостинице») и **устаревший год** (2020–2021).

**Приоритет:** ВЫСОКИЙ. Это фундаментальная проблема, которая должна быть решена на новом сайте на уровне nginx до запуска.

## Часть 3. Точки роста и причины отставания

### Причины текущего отставания

#### 1. Массовое дублирование контента (блоки 1, 6)

Отсутствие редиректов http→https, www→non-www, плюс второй домен gubernskayahotel.ru — совокупно создаёт 6+ версий каждой страницы. Без canonical поисковики не могут определить основную версию, ссылочный вес распределяется между дублями. **Это главная техническая причина нулевой видимости.**

#### 2. Отсутствие базовой технической SEO-инфраструктуры (блок 1)

robots.txt и sitemap.xml — отсутствуют. Это базовые элементы, без которых поисковик не получает карту сайта и директивы по индексации.

#### 3. Отсутствие мета-оптимизации (блок 6)

Ни на одной из проверенных страниц нет meta description. Title-теги не оптимизированы под целевые запросы. Нет canonical. Нет schema.org. Сайт «невидим» для расширенных сниппетов.

#### 4. SEO никогда не проводилось (блоки 2–6)

Подтверждено клиентом. Семантическое ядро не собиралось, конкурентный анализ не проводился, поисковая архитектура не проектировалась.

#### 5. Конкуренция агрегаторов (блок 3)

gesh.ru, Островок, Яндекс.Путешествия, Суточно — занимают топ-5 по большинству коммерческих запросов. Это системное ограничение рынка, а не проблема сайта.

### Точки роста

#### 1. Нишевые посадочные (блок 4)

Страницы «Семейный отдых», «Корпоративный отдых», «Новый год 2027», «Романтический отдых» — нет у большинства конкурентов. Создание этих посадочных + SEO-оптимизация = реалистичный путь в топ-3 по нишевым запросам.

#### 2. Микроразметка гостиницы (блок 1)

Hotel + HotelRoom + AggregateRating + FAQPage — даёт расширенные сниппеты в выдаче (звёзды, цены, FAQ). Конкуренты «Ольга» и «Снежный» — не обнаружена разметка. Первенство в разметке = конкурентное преимущество в выдаче.

#### 3. Информационный контент (блоки 4, 6)

«Как добраться до Шерегеша», «Карта трасс», «Что посмотреть в Горной Шории», «Когда лучше ехать» — высокочастотный информационный спрос, который конвертируется в бронирования. У «Ольги» уже есть раздел «О Шерегеше».

#### 4. Летнее направление (блоки 2, 4)

Растущий рынок (+23%/год по брифу), конкуренты не делают специализированных летних лендингов. Возможность захватить нишу первым.

#### 5. E-E-A-T преимущество (блок YMYL)

Booking 9.2 (105 отзывов), 2ГИС 4.9 (17), TripAdvisor Excellent (59), Островок 8.8 (61), Яндекс.Путешествия 304 отзыва — мощная доказательная база доверия, которая никак не используется на сайте. Вывод рейтингов + AggregateRating = мгновенное повышение CTR.

#### 6. Локальное SEO (блок «Сопровождение»)

Яндекс.Бизнес, Google Business Profile — карточки с фото, отзывами, ценами. Для локального бизнеса в туристическом регионе — один из главных каналов привлечения.

### KPI (диапазоны и динамика, не гарантии)

**Важная оговорка по сезонности:** Шерегеш — горнолыжный курорт. Пик спроса: ноябрь–апрель (загрузка 95–100%). Низкий сезон: май–октябрь (растущий, но значительно ниже). Все KPI имеют сезонную модуляцию. Усреднять годовые цифры некорректно.

| Период | Ожидаемая динамика |
|---|---|
| **0–30 дней (релиз)** | Индексация нового сайта, начало переиндексации. Возможно временное падение позиций (нормально при миграции). Подключение аналитики. |
| **30–90 дней** | Рост индексации до 80–100% страниц. Появление в топ-30 по 10–30 брендовым и нишевым запросам. Первые данные по CTR и поведению. |

| **180–365 дней** | Стабилизация позиций. Рост органического трафика. Оценка эффективности стратегии. Корректировка по данным Метрики и Вебмастера. |

**Что НЕ обещаем:**
- Конкретных позиций по общим запросам («отель шерегеш») — доминирование агрегаторов
- Конкретного объёма трафика без данных Wordstat (текущий замер — май, офф-сезон)
- Гарантий по конверсиям без данных Метрики

### Метрики для отслеживания

- Количество запросов в топ-10 / топ-30 (Яндекс, Google)

- Core Web Vitals (PageSpeed Insights)
- Конверсии: бронирования, звонки, заявки (Метрика — цели)
