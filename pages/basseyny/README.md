# Посадочная страница «Бассейны» — gubernskaya-hotel.ru

Свёрстана по образцу страницы [`/besedka-teplo/`](https://gubernskaya-hotel.ru/besedka-teplo/):
та же сетка (обложка → текстово-фотографические блоки в две колонки → блок цен → карта/подвал),
те же дизайн-токены, снятые с боевого сайта.

**Файл:** `index.html` — самодостаточная страница (CSS и JS внутри, внешних зависимостей нет,
кроме шрифта Manrope с Google Fonts и фотографий с Tilda CDN клиента).

---

## 1. Рекомендуемый URL

```
https://gubernskaya-hotel.ru/basseyny/
```

Транслитерация в стиле уже существующих URL (`/spa/`, `/banya/`, `/besedka-teplo/`, `/children/`).
После публикации:

- добавить в главное меню (в выпадающий блок «СПА» рядом с «Тренажерный зал»);
- перелинковать со страниц `/spa/`, `/children/`, `/activity/summer/` — это самые близкие по смыслу разделы;
- добавить в `sitemap.xml`.

## 3. Структура страницы

1. Шапка и хлебные крошки (Главная / СПА / Бассейны).
2. Обложка с H1 и лид-абзацем.
3. Плитка быстрых фактов: 4 бассейна · +28…+30 °С · 9:00–23:00 · 0 ₽ для проживающих.
4. **Бассейн в СПА-комплексе** — фото + характеристики + CTA «Узнать цены» и телефон СПА.
5. Широкое фото бассейна в СПА (открывается в лайтбоксе по клику).
6. **Детский бассейн в СПА** — зеркальный блок (2,8 × 1,2 м, глубина 0,3 м, +30 °С).
7. **Открытый бассейн на улице** — три карточки (большой у гостиницы, у апарт-отеля, детский)
   + широкое фото летней зоны отдыха.
8. Сводная таблица характеристик всех бассейнов.
9. Блок цен: бесплатно для проживающих + тарифы для не проживающих гостей + «Оплатить онлайн».
10. «Полезно знать»: что взять с собой, дети в бассейнах.
11. FAQ (аккордеон на `<details>`, без JS).
12. Финальный CTA на бронирование.
13. **Карта территории** — как на основном сайте: те же изображения карты, переключатель
    «Лето / Зима» и кликабельные метки поверх подписей, отрисованных на самой карте
    (метки «Бассейн» и «Детский бассейн» ведут на секцию уличных бассейнов,
    остальные — на /spa/, /banya/, /besedka-teplo/, /gubernskaya/, /apart-hotel/).
14. **Подвал** — повторяет подвал сайта: фон-фотография, «Как нас найти» + кнопка на Яндекс.Карты,
    строка контактов, «ЛФ Холдинг», горизонтальный логотип, соцсети (VK, Telegram, MAX, Дзен,
    RUTUBE), оценки 101Hotels / 2ГИС / Яндекс, юридическая строка и кнопка «наверх».

## 5. Что нужно уточнить у отеля перед публикацией

В коде эти места помечены комментарием `⚠️ УТОЧНИТЬ У ОТЕЛЯ` (секция «Полезно знать») и прочерками в таблице:

1. Точные даты работы уличных бассейнов (месяцы летнего сезона).
2. Габариты и глубина взрослого бассейна в СПА — в таблице стоит «—».
3. Требования к посещению: резиновая шапочка, сменная обувь, возрастные ограничения.
4. Нужна ли предварительная запись в СПА для не проживающих гостей в высокий сезон.
5. Есть ли детский тариф на посещение СПА для не проживающих гостей.

## 6. Технические заметки

- Адаптив: 1440 / 1100 / 900 / 640 / 520 px, горизонтального скролла нет ни на одном брейкпоинте
  (таблица скроллится внутри своего контейнера).
- Изображения — `loading="lazy"`, кроме обложки (`fetchpriority="high"` + `preload`).
- Лайтбокс галереи: 30 строк ванильного JS, доступен с клавиатуры (Tab / Enter / Esc), уважает `prefers-reduced-motion`.
- Ссылки в шапке, подвале, на карте территории и в CTA ведут на реальные разделы сайта.
- Карта территории: изображения `map-2.jpg` (лето) и `winter.jpg` (зима) — те же файлы, что на сайте.
  Подписи локаций нарисованы на самих картинках, поэтому поверх них лежат прозрачные ссылки-хотспоты,
  подсвечивающиеся коричневым при наведении (как в Tilda). Координаты хотспотов заданы в процентах,
  размер шрифта — в `cqw`, поэтому метки масштабируются вместе с картой на любом экране.
- Если страницу собирают в Tilda: блоки соответствуют стандартным — обложка T-Cover,
  два блока «текст + фото» (аналог блоков со страницы «Беседка»), плиточная галерея,
  блок цен на базе того же T396, что и на `/spa/`, и FAQ-аккордеон T585.
  HTML можно и вставить целиком через блок T123 — страница самодостаточна.
