# Вся страница /workshops одним блоком T123

Собрано по образцу готовой страницы `/warehouses`: весь контент — один блок
«HTML-код», без Zero Block и без зависимости от скриптов Tilda.

## Как внедрять

1. Создать новую пустую страницу (из шаблона — только хедер и футер).
   Временный адрес: `workshops-new`.
2. Настройки страницы → Главное: Title
   `Купить производственное помещение в СПб: цеха 500–1500 м² от 105 000 ₽/м²`.
   SEO → Description — из `../01_настройки_страницы.md`.
3. Добавить один блок **T123 «HTML-код»** и вставить `workshops_одним_блоком_T123.html` целиком.
4. Микроразметку из `../04_микроразметка.html` — в Настройки страницы → Дополнительно →
   HTML-код внутри HEAD. На время сборки туда же `<meta name="robots" content="noindex, nofollow">`.
5. Проверить по `../05_чеклист_после_публикации.md` и переключить адреса (раздел 7
   в `../ВСЁ_ДЛЯ_ВНЕДРЕНИЯ.md`).

## Что внутри

20 блоков ТЗ: первый экран с H1 и хлебными крошками, парк в цифрах, вводный
SEO-текст, каталог с планировками и комплексными решениями, технические
характеристики, генплан, что входит в цену, локация с картой, фотографии,
применение, цены, покупка против аренды, новый блок против вторички, этапы
сделки, документы, FAQ на 14 вопросов, заявка, текст низа с перелинковкой
и три CTA-строки.

- 1 тег H1, 17 H2, 6 H3 — весь текст в HTML, индексируется сразу.
- 14 кнопок ведут на `#zeropopup` — родную форму «Закажите обратный звонок».
- 16 изображений уже загружены в проект Tilda, у каждого заполнен alt.
- Карта — виджет Яндекса через iframe, грузится лениво.
- FAQ на `<details>`, работает без JS.
- Проверено на 1440 и 390 px: горизонтальной прокрутки нет.

## Чего в блоке нет

Формы как таковой: заявки идут через родной попап Tilda, иначе лиды не дойдут.
Интерактивной шахматки генплана — вместо неё изображение плана и кнопка запроса
свободных помещений.
