# Внедрение ТЗ на страницу vita-industrial.ru/workshops

Пакет для переноса ТЗ на живой сайт. Сайт собран на **Tilda** (проект 14118669,
страница 182345509), поэтому правки вносятся в редакторе Tilda — программно это
сделать нельзя: публичный API Tilda работает только на чтение, записи в нём нет.

## Что в пакете

| Файл | Что внутри |
|---|---|
| `01_настройки_страницы.md` | Title, Description, Open Graph, куда вставить стили и микроразметку |
| `02_тексты_по_блокам.md` | Все тексты страницы для копирования, по блокам |
| `03_правки_существующих_блоков.md` | Что изменить в блоках, которые уже стоят на странице |
| `04_микроразметка.html` | JSON-LD: Organization, BreadcrumbList, 4 × Product/Offer, FAQPage на 14 вопросов |
| `05_чеклист_после_публикации.md` | Что проверить, когда всё внесено |
| `html/00_общий_стиль.html` | Общий CSS для новых блоков — вставляется один раз |
| `html/блок_*.html` | Готовые блоки для вставки через Tilda T123 (HTML-код) |

Блоки свёрстаны в цветах и шрифтах сайта (#012d66, Oswald + Manrope), проверены
на 1440 px и 390 px: горизонтальной прокрутки нет, на мобильном колонки схлопываются.
FAQ собран на `<details>` и работает без JS.

## Порядок работы

0. **Копия страницы.** Скопировать страницу «Цеха», дать копии адрес `workshops-new`,
   закрыть её от индексации (`<meta name="robots" content="noindex, nofollow">` в HEAD) и дальше
   работать только на ней. Действующая `/workshops` не трогается. В конце адреса переключаются:
   старая уходит на `workshops-old` и снимается с публикации, новая получает `workshops`,
   тег `noindex` снимается. Подробный порядок — в `ВСЁ_ДЛЯ_ВНЕДРЕНИЯ.md`, разделы 0 и 7.

1. **Настройки страницы** — `01_настройки_страницы.md`.
   Title, Description, затем в «Дополнительно → HTML-код внутри HEAD» вставить
   `html/00_общий_стиль.html`, следом `04_микроразметка.html`.
2. **Правки существующих блоков** — `03_правки_существующих_блоков.md`.
   Начать с H1 и тегов заголовков: сейчас на странице ноль H2 и H3, это главная
   техническая проблема.
3. **Новые блоки — пять вставок.** Вместо того чтобы добавлять каждый блок отдельно,
   берите готовые пакеты из `html/пакеты/`: соседние блоки уже склеены в один кусок кода.
   Для каждого пакета добавить блок **T123 «HTML-код»** и вставить файл целиком.

   | Куда вставить | Файл | Что внутри |
   |---|---|---|
   | между первым экраном и каталогом | `пакеты/пакет_A_блоки_3-4.html` | 3 Парк в цифрах, 4 Вводный SEO-блок |
   | сразу после каталога (блок 5) | `пакеты/пакет_B_CTA_и_блок_6.html` | CTA-строка, 6 Технические характеристики |
   | вместо блока «Для каких бизнесов подходят наши склады» | `пакеты/пакет_C_блок_11.html` | 11 Для каких производств |
   | между блоком 11 и формой заявки | `пакеты/пакет_D_блоки_12-17.html` | 12 Цены, CTA, 13 Покупка или аренда, 14 Новый или вторичка, 15 Этапы сделки, 16 Документы, CTA, 17 FAQ |
   | между формой заявки и футером | `пакеты/пакет_E_блок_19.html` | 19 Текст низа и перелинковка |

   Отдельные файлы каждого блока лежат рядом в `html/` — они нужны, только если
   захотите вставлять блоки по одному или править что-то точечно.

4. **Проверка** — `05_чеклист_после_публикации.md`.

## Что заменить своими материалами

Текстов это не касается — они готовы. Заменить нужно только файлы и ссылки:

- `ССЫЛКА_НА_ФОТО.jpg` в блоке 4 — загрузить фото интерьера цеха в Tilda и подставить адрес.
- Ссылки на PDF в блоке 16 ведут на `/documentation` — заменить на прямые адреса файлов.
- Файл прайса `/files/price-vita.pdf` в блоке 12 — выгрузить и подставить адрес.
